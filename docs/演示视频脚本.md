## 镜头二 [0:40–2:20] 智能体演示

**命令**（终端逐条敲，敲完等结果再讲）：

```bash
# 1) 问数：SQL 通道
curl -s http://127.0.0.1:8000/chat -H "Content-Type: application/json" \
  -d '{"question":"计算机学院有多少学生？","role":"student","user_id":"S2023001","session_id":"demo1"}'

# 2) 政策问答：RAG 通道（不查库，查 95 篇政策文档）
curl -s http://127.0.0.1:8000/chat -H "Content-Type: application/json" \
  -d '{"question":"国家奖学金需要什么条件？","role":"student","user_id":"S2023001","session_id":"demo1"}'

# 3) 越权：学生问别人的成绩
curl -s http://127.0.0.1:8000/chat -H "Content-Type: application/json" \
  -d '{"question":"查一下 S2022005 的成绩","role":"student","user_id":"S2023001","session_id":"demo1"}'
```

**口播**：

> 先看智能体。第一个问题"计算机学院有多少学生"，它走的是 SQL 通道：先取表结构，再生成 SQL，执行，最后用自然语言把结果说出来。
> 注意返回里的 `channel` 字段，它明确告诉你这次走的是 SQL、RAG 还是混合——路由是显式的，不是黑盒。
> 第二个问题问奖学金条件，这类不进数据库，走政策通道：从九十五篇政策文档里检索，召回相关段落再回答，附出处。
> 第三个是我最在意的：学生问别人的成绩。它不是"答不出来"，而是**在生成 SQL 之前就拒绝**——权限校验在 SQL 重写层，服务端强制给私有表加 `student_id = 当前用户` 的谓词，同时拒绝 UNION 和子查询这类绕过写法。

**拍摄提示**：第 3 条一定要拍到"拒绝"的返回，这是安全设计的实证。

## 镜头四 [3:20–4:40] 全量评测套件

**命令**（小库现场跑，全量结果用报告讲）：

```bash
.venv/Scripts/python.exe -m testsuite.run_suite --db data/campus_small.db
```

**口播**：

> 第二层是端到端评测，545 条用例，八个维度：功能 150、多轮 109、安全 86、RAG 60、路由 50、边界 40、稳定 40、性能 10。
> 关键设计是**标准答案怎么来**：不是人工标注，是用 SQLite 直接执行同一张表算出来——数据库算的数就是标准答案，零人工、可复现。
> 判定也不是简单的字符串比对：SQL 结果做了语义等价，列顺序不同、数值精度差异都算对，但值不同就是错。
> 这一轮跑完是 545 条全过。但我更想让你看的是下一步——怎么证明这 545 条**真能抓到 bug**。

## 镜头五 [4:40–6:00] 变异测试（核心创新，务必讲透）

**画面**：终端里 M1–M10 的输出（提前跑好的日志或刚跑出的尾部），然后切 report.html 的变异热力图。

**口播**：

> 方法叫变异测试：我故意把代码改坏，看测试能不能发现。改坏了还不报警的测试，等于没写。
> 做了十个变异体，每个都对应一类真实故障：
> M1 把取表结构的工具删掉——工具调用维度掉 75%；
> M3 把权限过滤层删掉——安全维度直接掉到 0，测试立刻红；
> M5 把温度从 0 提到 1.2——稳定性维度掉 30%。
> 最值得说的是 M8 到 M10，这三类是**静默失效**：代码不崩、接口不报错，但结果是错的。
> M8 让模型把列名记错，执行直接失败，功能维度掉 96.7%；
> M9 把 WHERE 条件悄悄丢掉——这个最阴，SQL 能跑、有结果，只是结果是全表的，功能维度掉 63%；
> M10 让记忆只写不读，多轮约束从不生效，掉 100%。
> 十个变异体全部被杀死，Mutation Score 10/10。这就是"测试有效"的量化证据，不是我说它有效。

**拍摄提示**：M9 要停 2 秒重复一遍"能跑、有结果、但结果是错的"——这是全片最有说服力的一句。

## 四、常见翻车与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 跑批超过 8 分钟 | 全量库 + 变异测试耗时 | 用 `campus_small.db` 现场跑；全量用报告讲 |
| curl 中文乱码 | Windows 终端编码 | 先 `chcp 65001`；或改用 Postman 发 JSON |
| pytest 退出码非 0 | 沙箱 safe-delete 钩子拦清理 | 加 `--basetemp=_tmp_pt`；或只看 junit 读数 |
| /chat 返回 401 | 设了 `DATACLERK_AUTH_SECRET` | 演示环境不设该变量，或带上 token |
| 报告页打开是空白 | report.html 还没生成 | 先跑一次 `run_suite` 再录 |
